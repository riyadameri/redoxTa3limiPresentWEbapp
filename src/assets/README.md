# مجلد الأصول والشعارات (Assets Directory)

يمكنك وضع شعارك المخصص هنا في أي وقت:

- `src/assets/logo.svg` : الشعار بصيغة SVG (المستخدم افتراضياً في التطبيق)
- `src/assets/logo.png` : الشعار بصيغة PNG
- `public/assets/logo.svg` : متاح أيضاً للاستخدام المباشر عبر الروابط الثابتة

عند استبدال أي من هذه الملفات بشعارك، سيتم تحديث الشعار تلقائياً في كافة صفحات ومكونات المنظومة.
